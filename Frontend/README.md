# Frontend — AI Interview Guide & Resume Builder

React + Vite frontend for the AI Interview Guide and Resume Builder project.

## Tech Stack
- React 19, React Router 8, Axios, SCSS, Vite

## Setup
```bash
npm install
npm run dev
```

Set `VITE_API_URL` in a `.env` file pointing to your backend URL.

See the [root README](../README.md) for full project documentation.
